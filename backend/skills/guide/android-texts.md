# Android Texts
> Use when recruiting texts are on an Android phone; texts stay on the phone, so the student copies them from Google Messages for web.

Why no automatic route: Android keeps texts on the phone and offers no way for an outside app to read them (see docs/research/channels.md).

Steps:
1. On a computer, open Google Messages for web and pair it with the phone using Google's own steps.
2. Open the thread, select the messages with their dates and sender names, and copy them.
3. On Today → Add what's new, paste the thread. One conversation per paste.
4. Or save the copied text as a .txt file and upload it on Setup ("iMessage / SMS without the connector" card accepts .txt).

Tips:
- Keep the date lines: facts and "last contact" are dated from them.
- Phone numbers are never stored or shown; if a thread shows only a number, add the person's name in a first line.
- WhatsApp on Android is a different route: Export chat (skill `whatsapp`).

Do not:
- suggest third-party SMS backup apps or anything that reads the phone automatically;
- ask the student to forward texts to another number.
