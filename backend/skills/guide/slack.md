# Slack
> Use when recruiting conversations happen in Slack; school workspaces only allow admin-approved apps, so the student copies and pastes.

Why no automatic route: school Slack workspaces only let apps approved by their admins read messages, so copying is the free way in.

Steps:
1. Open the DM or thread.
2. Select the messages, including the lines with each sender's name and the time or date, and copy them.
3. On Today → Add what's new, paste them.
4. One conversation per paste. Leave out unrelated chatter.

Tips for a clean result:
- Dates matter: the agent dates each fact from the message dates, and works out words like "Thursday" from them. If the copy shows only times, add a line on top such as "Slack DM, date: YYYY-MM-DD".
- Names must appear in the text exactly as the person writes them; the app checks every name and quote against the paste.
- Channel announcements (events, deadlines, alumni posts) are fine to paste: they become dated leads.

After pasting, check the summary line: new people, updated people, leads, and anything the shield stopped.

Do not:
- ask for Slack tokens, workspace passwords or admin access;
- suggest installing a Slack app or bot in a school workspace.
